# Design Direction: Portofolio Azmi

## Identity
Personal developer portfolio. Dark, professional, modern — focused on clarity and craft.

## Palette
- Background base: `#0a0a0a` (near-black)
- Surface card: `#141414` / `#1a1a1a`
- Surface card border: `#2a2a2a`
- Accent primary: `#b5f000` (lime-green, used sparingly as the key focal color)
- Accent hover: `#cdff00`
- Text primary: `#f0f0f0`
- Text secondary: `#888888`
- Text muted: `#555555`

## Typography
- Font: **Satoshi** (from Fontshare CDN)
  - Regular 400 for body text
  - Medium 500 for labels/captions
  - Bold 700 for section headings
  - Black 900 for hero display text
- Reason: Satoshi has a geometric, confident character that fits a developer/creative personal brand.

## Mood / Personality
Dark, confident, minimal. No decoration for decoration's sake. Content-first layout.

## Accent Usage Rule
Lime-green is used ONLY at the key focal moment per section:
- Primary CTA buttons
- Active nav indicator
- Section highlight label
- Card hover state accent
